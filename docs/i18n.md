# Sistema de Internacionalização (i18n)

Este projeto implementa um sistema completo de internacionalização usando Next.js e next-intl, suportando inglês e português.

## 🌍 Idiomas Suportados

- **Inglês (en)**: Idioma padrão
- **Português (pt)**: Tradução completa

## 📁 Estrutura de Arquivos

```
messages/
├── en.json          # Traduções em inglês
└── pt.json          # Traduções em português

src/
├── i18n.ts          # Configuração do next-intl
├── middleware.ts    # Middleware para roteamento de idiomas
└── app/
    ├── page.tsx     # Redirecionamento para idioma padrão
    └── [locale]/    # Rotas dinâmicas por idioma
        ├── layout.tsx
        └── page.tsx
```

## 🔧 Configuração

### 1. Dependências
```bash
npm install next-intl
```

### 2. Configuração do Next.js
O `next.config.js` foi configurado para usar o plugin do next-intl:
```javascript
const withNextIntl = require('next-intl/plugin')('./src/i18n.ts');
```

### 3. Middleware
O middleware detecta automaticamente o idioma preferido do usuário e redireciona para a rota apropriada.

## 🎯 Como Usar

### 1. Nos Componentes
```typescript
import { useTranslations } from 'next-intl'

const MyComponent = () => {
  const t = useTranslations('navigation')
  
  return <h1>{t('title')}</h1>
}
```

### 2. Estrutura de Traduções
```json
{
  "navigation": {
    "title": "Navigation",
    "about": "About me"
  },
  "hero": {
    "welcome": "WELCOME.",
    "description": "Hi, I'm Kelvyn..."
  }
}
```

### 3. Acessando Traduções
```typescript
// Tradução simples
t('navigation.title')

// Tradução aninhada
t('hero.description')

// Com parâmetros (se necessário)
t('welcome', { name: 'Kelvyn' })
```

## 🔄 Alternância de Idiomas

O componente `LanguageSwitch` permite aos usuários alternar entre idiomas:

### Características:
- **Dropdown animado** com Framer Motion
- **Bandeiras dos países** para identificação visual
- **Persistência automática** via URL
- **Design responsivo**
- **Acessibilidade** com ARIA labels

### Localização:
- Posicionado na navegação lateral
- Disponível em todas as páginas
- Atualiza automaticamente o conteúdo

## 📱 URLs e Roteamento

### Estrutura de URLs:
- **Inglês**: `/en` (padrão)
- **Português**: `/pt`
- **Redirecionamento**: `/` → `/en`

### Navegação:
- Todas as rotas mantêm o prefixo do idioma
- Links internos preservam o idioma atual
- Navegação entre seções funciona em ambos os idiomas

## 🎨 Personalização

### Adicionando Novos Idiomas:

1. **Criar arquivo de tradução**:
```bash
# Criar messages/fr.json para francês
```

2. **Atualizar configuração**:
```typescript
// src/i18n.ts
const locales = ['en', 'pt', 'fr'] as const;

// src/middleware.ts
locales: ['en', 'pt', 'fr']
```

3. **Adicionar ao seletor**:
```typescript
// src/components/LanguageSwitch.tsx
const languages = [
  { code: 'en', name: 'English', flag: '🇺🇸' },
  { code: 'pt', name: 'Português', flag: '🇧🇷' },
  { code: 'fr', name: 'Français', flag: '🇫🇷' }
]
```

### Adicionando Novas Traduções:

1. **Atualizar todos os arquivos JSON**:
```json
{
  "newSection": {
    "title": "New Section",
    "description": "New content"
  }
}
```

2. **Usar nos componentes**:
```typescript
const t = useTranslations('newSection')
return <h1>{t('title')}</h1>
```

## 🔧 Troubleshooting

### Problemas Comuns:

1. **Tradução não aparece**:
   - Verificar se a chave existe no arquivo JSON
   - Confirmar o namespace correto no useTranslations

2. **URL não funciona**:
   - Verificar configuração do middleware
   - Confirmar que o idioma está na lista de locales

3. **Seletor não funciona**:
   - Verificar se o componente está dentro do NextIntlClientProvider
   - Confirmar que as rotas estão configuradas corretamente

### Debug:
